# LogiFlow - Moderne Logistiklösungen

[![Live Demo](https://img.shields.io/badge/demo-online-brightgreen.svg)](https://logiflowsaas.netlify.app/)

LogiFlow ist eine moderne, responsive SaaS-Plattform für Logistikunternehmen. Die Seite besticht durch ein elegantes Design, flüssige Animationen und eine benutzerfreundliche Oberfläche zur Optimierung komplexer Lieferketten.

## 🔗 Live Website
Besuchen Sie die Seite direkt unter: **[logiflowsaas.netlify.app](https://logiflowsaas.netlify.app/)**

## 🚀 Features

- **Modernes Design:** Ein professioneller Look mit Fokus auf Benutzererfahrung.
- **Responsive Layout:** Optimiert für Desktops, Tablets und Smartphones.
- **Interaktive Elemente:** Intuitive Navigation und ansprechende visuelle Effekte.
- **Transparente Prozesse:** Echtzeit-Einblicke in die Lieferkette.
- **Technologien:** Erstellt mit modernem HTML5, CSS3 und Pure JavaScript.

## 🛠️ Installation & Nutzung

1. **Repository klonen:**
   ```bash
   git clone https://github.com/BauerLba/LogiFlow.git
   ```
2. **Starten:**
   Öffne die `index.html` direkt in deinem Browser oder nutze eine lokale Server-Erweiterung (z.B. Live Server für VS Code).

## 📂 Projektstruktur

- `index.html` - Die Hauptstruktur der Website.
- `index.css` - Das gesamte Styling und die Animationen.
- `main.js` - Die Logik für Interaktionen und Dynamik.
